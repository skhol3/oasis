# Odoo 19.0 backend

What the [backend skill](../SKILL.md) needs on a 19.0 checkout. Read from the 19.0 source (commit 8a2481dfc); paths are relative to its root. The [15.0 reference](15.0.md) lists the same points for 15.0.

- Source layout: the ORM lives in `odoo/orm/` (`models.py`, `fields*.py`, `decorators.py`, `environments.py`, `commands.py`); `odoo/release.py` holds `version_info` and the Python range.
- Python: 3.10 to 3.14 (`MIN_PY_VERSION`, `MAX_PY_VERSION` in `odoo/release.py:39-40`); the default environment is 3.12.
- Display name: override `_compute_display_name` and, for searching, `_search_display_name(operator, value)` or `_rec_names_search` (`odoo/orm/models.py:1438`, `1455`). `name_get` and `_name_search` no longer exist.
- SQL constraints and indexes: declare `models.Constraint`, `models.Index` or `models.UniqueIndex` attributes (`odoo/orm/table_objects.py:79`, `125`, `185`). A `_sql_constraints` attribute is ignored with the warning "Model attribute '_sql_constraints' is no longer supported" (`odoo/orm/model_classes.py:162`).
- Grouping: `_read_group(domain, groupby, aggregates)` returns tuples (`odoo/orm/models.py:1867`); `read_group` is deprecated (`:2755`) and the web client uses `formatted_read_group` (`addons/web/models/models.py:802`).
- Field aggregation: `aggregator=`; `group_operator` is a deprecated alias (`odoo/orm/fields.py:485`).
- Cache: `flush_model`, `flush_recordset`, `invalidate_model`, `invalidate_recordset` (`odoo/orm/models.py:6372`, `6386`, `6728`, `6743`). For raw SQL, compose queries with `odoo.tools.SQL` (`odoo/tools/sql.py:46`).
- Access checks: `check_access(operation)` raises and `has_access(operation)` returns a boolean (`odoo/orm/models.py:4106`, `4123`); `check_access_rights` and `check_access_rule` are deprecated since 18.0.
- Controllers: `@route(type='jsonrpc')`; `type='json'` is a deprecated alias (`odoo/http.py:812`).
- Translations: `self.env._("...")` is available on the environment (`odoo/orm/environments.py:315`).
- Same in both series: `@api.model_create_multi`, `Command`, `with_company`, `_check_company`.
