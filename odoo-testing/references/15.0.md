# Odoo 15.0 testing

What the [testing skill](../SKILL.md) needs on a 15.0 checkout. Read from the 15.0 source (commit 3a28e5b0) and the series table of the oasis tools (`tools/odoo_versions.py`); paths are relative to the source root. The [19.0 reference](19.0.md) lists the same points for 19.0.

- Test classes: `TransactionCase`, `SingleTransactionCase`, `HttpCase`, `Form` and `tagged` all live in `odoo/tests/common.py` (`:803`, `879`, `1580`, `1884`, `2819`) and import from `odoo.tests` or `odoo.tests.common`. `SavepointCase` (`:869`) is a deprecated subclass of `TransactionCase` that warns on use; write `TransactionCase`.
- Tags: `@tagged('post_install', '-at_install')` as in 19.0; `test-module --only Class[.method]` becomes `--test-tags /<module>:Class.method`, which 15.0 supports (`odoo/tests/common.py:2842`).
- `--test-tags` does not imply `--stop-after-init` (`odoo/tools/config.py:534`); oasis passes it on every test run, so a run still ends.
- Demo data: loaded by default. oasis installs and tests with `--without-demo=all`: the option takes a value (`odoo/tools/config.py:111`), so bare it would swallow the next option. There is no `--with-demo`; `install-module --with-demo` and `init-dev-database --with-demo` pass nothing and get the default demo data.
- Tours: `import tour from 'web_tour.tour'; tour.register('name', { test: true, url: '/web' }, [steps])`, loaded from `web.assets_tests` and run with `self.start_tour(url, name, login=...)` (`odoo/tests/common.py:1767`).
- JavaScript unit tests: QUnit, bundled in `web.qunit_suite_tests` (`addons/web/__manifest__.py:498`).
- Second server port of a test run: `--longpolling-port`.
- Lint target: pylint-odoo must support `odoo_version` 15.0; the default environment is Python 3.9 (see the [Pylint guidance](pylint-odoo-guidance.md)).
