# Odoo 19.0 testing

What the [testing skill](../SKILL.md) needs on a 19.0 checkout. Read from the 19.0 source (commit 8a2481dfc) and the series table of the oasis tools (`tools/odoo_versions.py`); paths are relative to the source root. The [15.0 reference](15.0.md) lists the same points for 15.0.

- Test classes: `TransactionCase`, `SingleTransactionCase`, `HttpCase` and `tagged` in `odoo.tests` (`odoo/tests/common.py:990`, `1186`, `2230`, `2747`); `SavepointCase` no longer exists. `Form` lives in `odoo/tests/form.py:27`, imported as `from odoo.tests import Form`.
- Tags: `@tagged('post_install', '-at_install')` as in 15.0; `test-module --only Class[.method]` becomes `--test-tags /<module>:Class.method`.
- `--test-tags` implies `--stop-after-init`; oasis passes both anyway.
- Demo data: none unless `--with-demo` is given. oasis still passes `--without-demo` on install and test runs, and `install-module --with-demo` and `init-dev-database --with-demo` pass `--with-demo`.
- Tours: `registry.category("web_tour.tours").add("name", { steps: () => [...] })`, loaded from `web.assets_tests` and run with `self.start_tour(url, name, login=...)` (`odoo/tests/common.py:2590`).
- JavaScript unit tests: Hoot, bundled in `web.assets_unit_tests` (`addons/web/__manifest__.py:438`).
- Second server port of a test run: `--gevent-port`.
- Lint target: pylint-odoo must support `odoo_version` 19.0 on Python 3.12 by default (see the [Pylint guidance](pylint-odoo-guidance.md)).
