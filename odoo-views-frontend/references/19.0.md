# Odoo 19.0 views and frontend

What the [views and frontend skill](../SKILL.md) needs on a 19.0 checkout. Read from the 19.0 source (commit 8a2481dfc); paths are relative to its root. The [15.0 reference](15.0.md) lists the same points for 15.0.

- List views: the view type and root element are `list` (`<list>`, `view_mode` `list`; `odoo/addons/base/models/ir_ui_view.py:149`). `tree` is not a view type.
- Modifiers: `invisible`, `readonly`, `required` and `column_invisible` take a Python expression directly, such as `invisible="state != 'draft'"` (`VIEW_MODIFIERS`, `ir_ui_view.py:34`). A view with `attrs` or `states` is refused: "Since 17.0, the "attrs" and "states" attributes are no longer used." (`:495-497`).
- Owl 2 (`addons/web/static/lib/owl/owl.js`, version 2.8.4). Every view, field widget and service is an Owl component or ES module under `addons/web/static/src` (`@web/...` imports); register them in `registry.category("views")`, `registry.category("fields")` or `registry.category("services")`.
- QWeb: use `t-out`; in developer mode `t-esc` logs "Found deprecated directive @t-esc ... Replace by @t-out" (`odoo/addons/base/models/ir_qweb.py:2491`).
- Assets: `web.assets_backend` and `web.assets_frontend` in the manifest's `assets`; tours load from `web.assets_tests` (`addons/web/__manifest__.py:425`).
- Tours: `registry.category("web_tour.tours").add("name", { steps: () => [...] })` (`addons/web_tour/static/src/js/tour_service.js:67`).
- JavaScript unit tests: Hoot (`addons/web/static/lib/hoot`), bundled in `web.assets_unit_tests` (`addons/web/__manifest__.py:438`).
