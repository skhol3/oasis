# Odoo 15.0 views and frontend

What the [views and frontend skill](../SKILL.md) needs on a 15.0 checkout. Read from the 15.0 source (commit 3a28e5b0); paths are relative to its root. The [19.0 reference](19.0.md) lists the same points for 19.0.

- List views: the view type and root element are `tree` (`<tree>`, `view_mode` `tree`; `odoo/addons/base/models/ir_ui_view.py:243`). `list` is not a view type.
- Modifiers: conditions on record values are domains in `attrs`, such as `attrs="{'invisible': [('state', '!=', 'draft')]}"` (also `readonly`, `required` and, in a `tree`, `column_invisible`), and `states="draft,sent"` shows an element only in those states (`transfer_node_to_modifiers`, `odoo/addons/base/models/ir_ui_view.py:82-110`; example: `odoo/addons/base/views/res_partner_views.xml:91`). A plain `invisible`, `readonly` or `required` is evaluated once against the context only, such as `invisible="1"` or `invisible="context.get('hide')"`, never against field values like the 19.0 expressions; in a `tree`, `invisible` hides the column.
- Owl 1 (`addons/web/static/lib/owl/owl.js`, version 1.4.11) runs the new web client, the search and the graph and pivot views (`addons/web/static/src`, `/** @odoo-module **/` files). Form, list and kanban views and most field widgets are still legacy: `odoo.define` modules under `addons/web/static/src/legacy/js` (`AbstractField`, `web.field_registry`, `web.field_registry_owl`), which `registry.category("fields")` wraps (`addons/web/static/src/fields/fields.js`). Extend a form or list widget the legacy way.
- QWeb: `t-out` exists; `t-esc` and `t-raw` still work as deprecated uses (`odoo/addons/base/models/qweb.py:1088-1142`).
- Assets: `web.assets_backend`, `web.assets_frontend` and `web.assets_qweb` for templates in the manifest's `assets` (`addons/web/__manifest__.py:41`, `85`); tours load from `web.assets_tests` (`:448`).
- Tours: `import tour from 'web_tour.tour'; tour.register('name', { test: true, url: '/web' }, [steps])` (`addons/account/static/tests/tours/tax_group_tests.js`).
- JavaScript unit tests: QUnit, bundled in `web.qunit_suite_tests` (`addons/web/__manifest__.py:498`).
