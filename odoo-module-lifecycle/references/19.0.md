# Odoo 19.0 module lifecycle

What the [module lifecycle skill](../SKILL.md) needs on a 19.0 checkout. The values are the 19.0 row of the series table of the oasis tools (`tools/odoo_versions.py`), read from the 19.0 source (commit 8a2481dfc). The [15.0 reference](15.0.md) lists the same points for 15.0.

- Version proof: `odoo/release.py` declares `version_info = (19, 0, ...)` (doctor `odoo_release=19.0`); module manifests carry `19.0.x.y.z` versions, and a module of another series fails doctor's `module_series`.
- Demo data: Odoo 19.0 loads none unless `--with-demo` is given. `install-module` and test runs still pass `--without-demo`; `install-module --with-demo` and `init-dev-database --with-demo` pass `--with-demo`.
- Users: `init-dev-database` writes the groups of `[development]` users to `res.users.group_ids`.
- Second server port: `--gevent-port` (`gevent_port` in `odoo.conf`), given a free one on test runs and linked worktrees.
- Tests: `--test-tags /<module>[:Class.method]` implies `--stop-after-init`; oasis passes both.
- Developer mode: `--dev=access,qweb,reload,replica,xml` (`all` is `access,qweb,reload,xml`).
