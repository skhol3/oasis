# Odoo 19.0 security

What the [security skill](../SKILL.md) needs on a 19.0 checkout. Read from the 19.0 source (commit 8a2481dfc); paths are relative to its root. The [15.0 reference](15.0.md) lists the same points for 15.0.

- User groups: `res.users.group_ids` holds the groups given explicitly and `all_group_ids` adds the implied ones (`odoo/addons/base/models/res_users.py:257-258`). In data files and tests write `group_ids`.
- Groups: `res.groups.user_ids` lists the users (`odoo/addons/base/models/res_groups.py:17`); a group belongs to a privilege, `privilege_id` (`res.groups.privilege`, `:36`), whose `category_id` is the application (`odoo/addons/base/models/res_groups_privilege.py:13`).
- Membership: `self.env.user.has_group('module.xml_id')` and `has_groups('a,!b')` for a group specification (`odoo/addons/base/models/res_users.py:1034`, `1066`).
- Access checks: `records.check_access('write')` raises, `records.has_access('write')` returns a boolean, both covering ACLs and record rules (`odoo/orm/models.py:4106`, `4123`); `check_access_rights` and `check_access_rule` are deprecated since 18.0.
- Record rules: `ir.rule.groups` (`odoo/addons/base/models/ir_rule.py:25`), as in 15.0.
- JSON routes: `@route(type='jsonrpc')`; `type='json'` is accepted as a deprecated alias (`odoo/http.py:812`).
