# Odoo 15.0 security

What the [security skill](../SKILL.md) needs on a 15.0 checkout. Read from the 15.0 source (commit 3a28e5b0); paths are relative to its root. The [19.0 reference](19.0.md) lists the same points for 19.0.

- User groups: `res.users.groups_id` (`odoo/addons/base/models/res_users.py:367`). In data files and tests write `groups_id`; `group_ids` and `all_group_ids` do not exist.
- Groups: `res.groups.users` lists the users (`odoo/addons/base/models/res_users.py:201`) and `category_id` (`ir.module.category`, `:208`) is the application; there are no privileges (`res.groups.privilege`).
- Membership: `self.env.user.has_group('module.xml_id')` (`odoo/addons/base/models/res_users.py:895`) and, on any model, `self.user_has_groups('a,!b')` for a group specification (`odoo/models.py:1466`); `res.users.has_groups` does not exist.
- Access checks: `check_access_rights(operation, raise_exception=True)` for ACLs and `check_access_rule(operation)` for record rules, called separately (`odoo/models.py:3559`, `3565`); `check_access` and `has_access` do not exist.
- Record rules: `ir.rule.groups` (`odoo/addons/base/models/ir_rule.py:23`), as in 19.0.
- JSON routes: `@route(type='json')` (`odoo/http.py:451`).
