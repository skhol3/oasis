Patch release: closes the open findings of the Gentle Shell audit (odd/tasks/v0.4.1.md, memory
oasis/skills-and-gentle-shell-audit) and the advisories of the v0.4.1 reviews. No contract changes.

## Specs

- S1. User: "vamos con los hallasgos de la auditoria e investigacion".
- S2. Bash guard, still blocks too much: a heredoc body is classified as commands only when a
  command on the opener line reads it (`git add . && git commit -F - <<'EOF'` with a body starting
  with `psql` is allowed; a quoted word such as "fix ssh" does not count).
- S3. Bash guard, coverage lost in v0.4.1 is restored: a comment after `;`, `&&`, `|` or `(`; `#`
  after an escaped space is not a comment; a heredoc whose reader is on a continuation line or after
  a trailing pipe; readers ksh, mksh, ash, fish, csh, tcsh; `docker exec … sh <<EOF`.
- S4. Audit finding 2: `--help`/`-h` of the user-run commands (migrate, worktree-init) is not blocked;
  everything else stays user-run.
- S5. Audit finding 5: the prompt section names only the oasis tools the session has; with none it
  points to the CLI.
- S6. Review advisories: the heartbeat is covered by a test; the /oasis subcommands have one source
  for completion, usage, description and dispatch.
- S7. Audit finding 4: README and AGENTS.md document installing the Gentle Shell package from the
  release tag.
