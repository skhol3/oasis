# Odoo 19.0 environment

What the [environment skill](../SKILL.md) needs on a 19.0 checkout. The values are the 19.0 row of the series table of the oasis tools (`tools/odoo_versions.py`), read from the 19.0 source (commit 8a2481dfc). The [15.0 reference](15.0.md) lists the same points for 15.0.

- Release: `odoo/release.py` declares `version_info = (19, 0, ...)`; `oasis doctor` reports it as `odoo_release=19.0` and, in a workspace with several series, `series=19.0`. Module manifests carry `19.0.x.y.z` versions (doctor `module_series`).
- Python: 3.10 to 3.14 (`odoo/release.py:39-40`); a workspace without named environments uses 3.12, the Python of the official 19.0 package (`FROM ubuntu:noble`).
- PostgreSQL: 13 or newer; `oasis setup` writes a compose file with `postgres:17`.
- Second server port: `--gevent-port`, `gevent_port` in `odoo.conf`; a linked worktree's starts after it.
- Developer mode: `--dev=` takes `access`, `qweb`, `reload`, `replica`, `xml`; `all` is `access,qweb,reload,xml`. There are no debugger features. `reload` needs `inotify` or `watchdog`.
- Runtime requirements: the source's `requirements.txt` is enough; `oasis setup` adds nothing to `runtime.in`.
